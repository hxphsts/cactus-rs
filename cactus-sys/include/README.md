# Vendored header

`needle.h` is an unmodified copy of the header Cactus Compute publishes next to every engine archive
at [Cactus-Compute/needle3](https://huggingface.co/Cactus-Compute/needle3), taken at commit
`9da75122d4ca11aa4a667281c9c8ba38a7eed679` (`macos-arm64/needle.h`, identical on all fifteen
platforms). Copyright Cactus Compute, licensed under Apache-2.0.

It is kept for reference only. Nothing compiles it: the declarations in `src/needle.rs` are written by
hand to match it.
